Agent
any model · any platform
Skills are model-invocable. The same SKILL.md runs in Claude Code, Cursor, Copilot CLI, Gemini CLI. Per-provider overrides pick the right model at runtime. 
model: opus           # default tier
metadata.model:
  openai: o3
  google: gemini-2.5-pro
  cursor: composer-2

SKILL.md
one file · yaml + markdown
Frontmatter is the contract: name, description, allowed-tools, model, CalVer version. Body is imperative instructions. 
name: wk:pr-resolve
allowed-tools: [Bash, Read, Edit]
version: '2026.04.22-070656'

wk:sharpen
distiller · the engine
Scans learnings + global memory. Extracts the principle, never the specific example. Patches SKILL.md, renames learning → *.learned.md, logs to .distilled-sources.log.
  • ❌ "check lines 232 and 60 in trust-boundaries.md"
  • ✅ "confirm each comment's target line exists in the diff"

severity: low | medium | high
