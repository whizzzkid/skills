`.review-playground/` directories are disposable scratch space generated by `wk-pr-review` and safe to discard during worktree cleanup.

**What happened:** Cleanup blocked repeatedly because nearly every merged worktree had untracked `.review-playground/` content (repro scripts, analysis docs, HTML reports). Treated as potentially-valuable context requiring preservation; user clarified it is disposable.

**Root cause:** `.review-playground/` is `wk-pr-review`'s working directory for ad-hoc experiments. It is never committed and has no lasting value — the relevant findings are already posted to the PR as review comments before merge.

**Suggested fix:** wk-worktree-cleanup should auto-classify `.review-playground/` (and `.gitignore` IDE noise) as trivially clean: skip retro check and allow `git clean -fd` of those paths without requiring user confirmation per worktree.
