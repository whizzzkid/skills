## Session-2

### What worked

- Independent PR decomposition: 7 UX issues mapped to 4 PRs grouped by dependency, all merged cleanly without conflicts.
- Playwright MCP for visual verification of CSS/UI fixes caught a theme-toggle click issue and provided an alternative (`browser_evaluate`) for screenshot capture.
- Copilot review comment resolution flow (fetch via `gh api`, apply fix, push) worked smoothly across two PRs.

### What could've been better

- workflow: Dispatched 4 parallel agents with worktree isolation despite the skill's own HARD RULE documenting that isolated agents cannot run Bash — required manual recovery for all 4 (build, test, commit, push, PR creation). The live learning was captured but the rule was already in the skill text at dispatch time.
- workflow: Git rebase/push operations should be narrated with explicit before/after SHAs so the user can verify nothing was lost, reducing false-alarm corrections.
