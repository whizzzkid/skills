## Session-1

### What worked
- Pull the real upstream framework source at the pinned version before trusting a reviewer's claim about framework behavior; it confirmed one bot blocker and showed its suggested fix would have disabled the feature.
- Mutation-check every new spec (break the code, confirm a red run, restore from a copy) before claiming coverage.
- A real-database canary test (provoke the actual error) catches driver message drift that string-stubbed tests miss.

### What could've been better
- commit: an implement directive under wk-workflow authorizes the first push; never pause to confirm.
- jira: run ticket detection when an investigation pivots to a code change, and offer to create one before the first commit.
- pr: re-poll unresolved review threads on the current head after every push before reporting status; green CI plus "review required" is not done.
- adversarial-review: when porting a resilience mechanism, check side effects on open transactions and connection ownership, not only the happy-path recovery.
- devcontainer: on a host-port clash with a sibling worktree, start with a ports-reset override plus devcontainer labels so hooks can find the container.
