## Session-1

### What worked
- Playwright MCP + mermaid.live validation: once actually opened in browser, immediately caught the semicolon-in-label syntax error. The base64-encoded URL approach was solid and survived private-repo auth issues.
- Systematic Mermaid fixes: angle brackets → HTML-safe form, Unicode symbols → ASCII, `opt` block → `Note over` block, semicolon → comma in message labels.
- PR merge and ticket transition workflow clean and uneventful—CI green, reviews approved, merge immediate.

### What could've been better
- **wk-mermaid** (routed to `wk-learn`): Deferral of browser validation defeated the purpose of the guidance. When editing multiple Mermaid diagrams, must validate BOTH in the browser immediately, not postpone until user redirect. The first diagram was validated, but the second deferred—breaking the non-negotiable requirement written in the mermaid learning itself.
- **Testing coverage**: Both diagrams should have been validated in the same pass (back-to-back mermaid.live checks) rather than validating one, committing, then discovering the second needs a fix only after user feedback.
