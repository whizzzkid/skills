## Session-1

### What worked
- Identifying a single fix point (`buildClaudeArgs`) that covered both checks and validators — one change, full coverage, no call-site scatter.
- Staging self-review comments as a pending review in parallel with CI polling shortened wall-clock time to ready.

### What could've been better
- [wk-docs]: When editing a doc that has both a narrative section and a risk/summary table covering the same concept, grep the whole document for related terminology before committing — cross-section inconsistency (e.g., present-tense assertion vs. "(planned vX.Y)" qualifier in the risk table) won't surface in a diff review.
- [wk-adversarial-review]: After changing a "default/fallback" constant, grep all display-label and logging functions that format or return the old fallback string; stale string literals in logging paths read as correct model names to operators.
