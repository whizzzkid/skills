## Session-1

### What worked
- Route every finding through an independent reproduce-or-refute verifier; it caught a false required-status claim the implementer had shipped.
- Mutation-check each new spec against a pre-mutation copy restored with cmp, never through git.

### What could've been better
- gh: verify required statuses via the branch rules API before claiming a red build cannot block a merge.
- workflow: enumerate every termination class (exit codes, exceptions, signals, refused updates, before/after success) before publishing an "every path" invariant.
- workflow: diff production files before committing while mutation-testing agents share the working tree.
- learn: self-caught errors this session were captured only at retro time, not live in the response that caught them.
