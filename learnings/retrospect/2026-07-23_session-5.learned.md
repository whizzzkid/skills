## Session-5

### What worked
- After a base-branch-policy merge block, resolving all unresolved threads (author self-review + a Minor bot thread, with user go-ahead) is the correct unblock path — the squash then succeeds without admin override.

### What could've been better
- wk-pr-resolve: a "land this / resolve to merge" invocation is standing authorization to post replies and resolve threads, not just to push — splitting it into a redundant confirmation ask reads as unpredictable.
- wk-adversarial-review: when a diff documents authoring guidance and also adds an example/fixture of that artifact, grep the fixture against the rule the same PR just wrote — a fixture that violates its own PR's docs slipped past the sweep.
