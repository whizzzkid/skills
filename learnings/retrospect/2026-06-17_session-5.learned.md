## Session-5

### What worked
- Adversarial review caught both a silently-dropped telemetry sidecar and a missing prompt injection boundary before the PR was marked ready — the mandatory pre-ready gate earns its cost.
- Stacked PR split (infra PR then classifier PR) let each land independently with clean CI.

### What could've been better
- wk-pr: base detection silently skips local-only branch candidates because `git fetch origin "$CAND" || continue` exits on fetch failure — branches that exist locally but are not pushed to origin are dropped from the candidate set, leaving BEST_DIST at the sentinel 999999 and falling back to the default branch incorrectly.
