## Session-3

### What worked
- Running a deleted-mode's surviving alternative end to end caught a documented command that had never been executable.
- Verifying CI per-job instead of trusting the green rollup surfaced a review gate that is not wired in at all.
- Folding every review residual into one amend, then re-running all local gates before pushing, kept the branch at a single commit.

### What could've been better
- workflow: once a defect and its owning file are both identified, the next action must be an edit — a turn that produces no new facts should not produce more analysis.
- buildkite: confirm a named check has a matching job in the build before reporting its outcome; an absent step renders identically to a pass.
- adversarial-review: evaluate conditional skip-guards against the value the runtime actually supplies — a predicate that never matches silently disables every test it was added to protect.
- adversarial-review: when a diff removes one of several documented alternatives, execute each survivor verbatim; the deletion makes a pre-existing defect load-bearing.
- commit: a regenerated vendored artifact re-stamps host-platform constants, so name the generator and platform in the commit body or the churn reads as collateral damage.
- self-review: author inline-comment payload files with the Write tool by default, since review prose routinely contains slashes a path-scanning hook mistakes for a path.
