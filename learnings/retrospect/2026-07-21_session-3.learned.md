## Session-3

### What worked
- Confirming a diagnosis by matching produced artifact fingerprints (compiled asset digests) against the exact failing artifacts (404'd filenames) turns a plausible root cause into a proven one.
- Reusing a repo's existing env-override convention to inject build-time config beats editing a generated "DO NOT EDIT" file — satisfies both the fix and the local-repro ask with one mechanism.

### What could've been better
- workflow: when reproducing a full boot that resolves secrets through a config layer, enumerate all required keys upfront from the schema/existing env-override file instead of discovering them one boot-failure at a time.
