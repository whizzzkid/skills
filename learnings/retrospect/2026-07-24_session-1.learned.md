## Session-1

### What worked
- Refute adversarial-review candidate blockers by reproducing them, not by arguing — all three raised this session died on a reproduction attempt.
- Derive validation bounds from the live schema rather than hardcoding them, so a widening migration needs no code change and a drift-guard spec fails in CI instead of in staging.
- Publish the contract clients need (maxLength per field) in the same change that enforces it, so producers can bound their own input instead of discovering the limit by losing data.

### What could've been better
- workflow: after one failed profile-source attempt, a credential injected by a secrets manager is stale in-process — ask for a session restart instead of hunting further shell files.
- bash: never emit `sed -i` in a cross-platform command; use `perl -pi -e` for in-place edits.
- testing-skeleton: ad-hoc database probes through a framework runner commit by default — roll them back or re-prepare the test database before the next suite run.
