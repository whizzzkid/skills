## Session-4

### What worked
- Golden-fixture parity files consumed by both language suites (Ruby/bash, Ruby/Go) pinned cross-language gate behavior and caught divergence for free -- reuse this pattern whenever the same predicate exists in two runtimes.
- Triaging late bot rounds as Minor-only and offering merge-with-deferred-follow-ups (handoff prompts file) stopped a review-thrash loop without losing the findings.

### What could've been better
- pr-resolve: after pushing fixes, re-query unresolved threads and assert every addressed thread is resolved before declaring the round done -- a push is not the completion signal.
- adversarial-review: add a hunt category for state inferred from a rendered artifact (summary/report) -- gate the inference on the artifact's non-degraded production path, not its existence.
- adversarial-review: an errexit-suspension finding in one shell function must trigger a sweep of every sibling function invoked from a conditional context in the same library.
