## Session-1

### What worked
- A refutation-based review (two skeptics per finding) over the whole stacked diff caught a real retry-policy defect that every per-PR test and CI run had passed.
- Negative controls (temporarily reverting the fix and re-running the targeted specs) proved each new guard was load-bearing before committing.

### What could've been better
- env: probe login-shell env for presence before telling the user a variable is unset.
- workflow: when adding a raise-to-retry path, spec the job's retry-delay and exhaustion hooks directly.
- devcontainer: guard the test suite against dev-only container env overrides.
