## Session-5

### What worked
- Running the local binary before every push caught stale findings from prior iterations; the pre-push gate cleared correctly once reverted code was committed.
- Using `.fetch` over bracket access in partition predicates enforced fail-fast nil behavior at the decision boundary, making downstream formatter crashes impossible.
- Keeping visibility constants separate from approval-gate constants decoupled two concerns that looked identical today, preventing bot re-fire when one list diverges.

### What could've been better
- wk-pr-resolve: Judgment-required consultation messages must include the full suggestion block (comment body, fix plan, skip rationale) per item — bare letter+code references ("A+C, D, B") are unreadable without that context, even when the count gate passes.
- wk-adversarial-review: The pre-push gate has no explicit named step for running the local binary; the check exists only in memory, not in the skill's procedure, so it gets skipped under time pressure.
