## Session-6

### What worked
- Formally re-running adversarial review after a compaction (rather than trusting informal pre-compaction fixes) surfaced a genuinely new blocker the earlier pass missed — treat a persisted clearance record or a fresh run as the only valid gate.
- The scoped-skip provision (narrow, empirically-verified single-blocker fix → manual clearance record instead of a full re-dispatch) kept the fix loop tight without re-running the whole flow.

### What could've been better
- adversarial-review: three separate shell-safety bugs (grep/||-precedence, tput under set -e, unquoted array word-splitting) all landed in one hand-authored bash hook, so the mechanical sweep catalog under-covers bash string/array quoting and command-arg construction — extend it to flag echo-piped-to-xargs string building re-expanded unquoted and empty-array expansion under set -u.
- jira: resolving the Cloud tenant by guessing an org-name subdomain slug produced a 404; default to calling the accessible-resources endpoint first (or cache the resolved cloudId/hostname) rather than inferring the subdomain from the org name.
