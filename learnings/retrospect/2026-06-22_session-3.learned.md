## Session-3

### What worked
- Adversarial-review gate caught and fixed two real issues (dead guard, downgrade-protection merge) before push — the two-pass framework prevented silent bugs without being overly conservative.
- Spec-first split planning held accuracy after codebase grew 1.6k lines — solid upfront architecture reduced mid-execution rework.

### What could've been better
- `wk-pr`: When creating a stacked PR series (PR1 → PR2 → PR3 → PR4), the skill should auto-detect branch bases and inject canonical cross-references into PR descriptions. Manual link-adding post-creation breaks the DRY principle and creates maintenance debt (updating descriptions later requires manual re-linking). Detect base == PR{N-1} branch and auto-populate `[#NNN](...)` references in the body template, or surface a prompt asking whether to inject them.
