## Session-7

### What worked
- Driving the restore/reset flows in a real browser before declaring done caught two lifecycle bugs the fake DOM harness could not model.
- A multi-lens adversarial workflow with one skeptic per finding downgraded an over-severe blocker and surfaced real mutation survivors, each fixed with a regression test.

### What could've been better
- workflow: run the real-browser check right after the first wiring commit, not after docs, so lifecycle bugs land before the PR is published.
- testing-skeleton: when a failure passes in isolation, fix the earliest failing test first; leaked timers cascade into later tests through re-resolved globals.
- devcontainer: compose project names are lowercased by the devcontainer CLI; shutdown commands must lowercase the basename too.
