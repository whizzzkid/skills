## Session-1

### What worked
- Running an adversarial subagent on a docs-only skill file surfaced 2 blockers and 2 majors before push; iterating 3 rounds produced a materially more robust spec than the first draft.

### What could've been better
- wk-workflow: After CI passes on a push to a draft PR, call `gh pr ready` in the same turn — never end a turn delegating that step to the user.
- wk-pr-resolve: Run pr-resolve after every new push, not just the initial one — bot reviewers post fresh findings on each push and the retro must not run until all new threads are addressed.
