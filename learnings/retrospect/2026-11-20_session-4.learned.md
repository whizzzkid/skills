## Session-4

### What worked
- Pipeline each change through implement, then an independent verifier, then a refute-skeptic: three rounds surfaced
  distinct defect classes that a single review missed.
- Browser-verify restore and persistence UX by counting network requests and checking a window marker, not just DOM text.

### What could've been better
- testing-skeleton: fake framework harnesses must model element teardown and rebuild between lifecycle events; state
  kept on an instance passed every test until a reviewer read the renderer source.
- devcontainer: parallel stacks started via raw compose need devcontainer labels, or hook fallbacks cannot exec.
- pr: screenshot upload to internal hosting can be blocked by permission policy; ask the user up front for an
  approved attachment route instead of discovering it at PR time.
