## Session-1

### What worked
- Subtractive fix pattern: removing the scroll listener fixed the toolbar jitter — no new code needed
- Schema migration with cursor-walk backfill handled corrupt/missing rows gracefully
- ADR discipline maintained: three new ADRs written, one superseded, index updated atomically

### What could've been better
- wk-workflow: Never claim CI green without running `gh pr checks` against the current HEAD SHA — was called out twice for false claims
- wk-pr: After creating PRs, always run `gh pr ready` before moving on — left all PRs as draft
- wk-pr-resolve: After every push, poll for bot review comments and address them in the same pass — user had to ask twice
- wk-workflow: When user explicitly requests a tool (e.g. `gh stack`), execute it immediately or report the blocker — do not silently drop the ask
- wk-pr: After a parent PR merges, immediately rebase all child branches onto the new base and force-push — do not wait for the user to discover merge conflicts
