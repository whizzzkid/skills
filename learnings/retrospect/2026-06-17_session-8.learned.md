## Session-8

### What worked
- Running a second-opinion review tool in parallel with adversarial review produced independent corroboration of findings; the overlap validated both passes without extra cost.
- Pre-push hook caught a non-ASCII character in a pipeline template file outside the primary diff scope — hook coverage extends beyond staged files.

### What could've been better
- wk-commit: After editing an already-staged file, re-staging is required (`git add <file>`) before committing — the index is a snapshot not a live mirror of the working tree. Skipping this causes the pre-commit hook to inspect stale staged content and block the commit with offenses already fixed in the working tree.
