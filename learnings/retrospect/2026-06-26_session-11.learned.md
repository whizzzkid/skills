## Session-1

### What worked
- Live API testing on real PRs before finalizing the detection approach prevented shipping with wrong event type assumptions.
- Running the the pre-push review binary binary locally surfaced a DRY issue and stale doc before CI — binary confirmed no blockers/majors.

### What could've been better
- wk-pr: self-review must launch in parallel with CI immediately after `gh pr create`; deferring to after CI green is a recurring HARD RULE violation.
- wk-pr: the pre-push review binary binary run (`$HOME/.local/bin/<review-binary> local --quiet`) must be an explicit numbered step in the adversarial-review gate, not just a memory note.
- wk-commit: plan docs are working artifacts in this repo and must never be staged; only spec docs belong in committed history.
