## Session-1

### What worked
- Build the eval harness before refactoring skills, so every later change has a deterministic gate to pass.
- Route model evals through the local claude binary with isolated flags (empty cwd, no setting sources, tools, skills, or MCP) so no separate API key is needed and user config never contaminates the baseline arm.
- Turn a recurring human audit into a pre-commit hook (HARD RULE count) the moment it catches a real regression.

### What could've been better
- commit: never disable hooks via env vars (LEFTHOOK=0) to get past one gate; satisfy the gate, and stage explicit paths when untracked files predate the task.
- workflow: probe the repo's direct-to-default convention before the first commit, not at PR time.
- workflow: open files for the user with $IDE/$VISUAL, never the OS default opener.
- sharpen: verify sub-agent de-bloat claims mechanically (rule counts + phrase audit); never delete a repeated section that is a runtime trigger without shipping its replacement.
- workstyle-shell: use [ \t]*$ instead of \s*$ in line-mode perl substitutions.
