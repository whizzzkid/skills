## Session-1

### What worked
- Background task monitoring (build watch) ran in parallel with comment triage, freeing interactivity.
- Conflict resolution + RBI regeneration → passing CI (#NNN) on first re-run after merge.
- Distinguishing already-resolved vs. pre-existing blocker issues prevented false escalations.

### What could've been better
- **wk-pr-merge**: Minor findings should not prompt follow-up filing before merge; offer to file post-merge instead. Current flow reads as "propose, ask, proceed anyway" — ambiguous whether the ask gates the merge.
- **git signing**: When commit fails with "Couldn't find key in agent?", compare configured key against loaded keys first before asking for config changes. Root cause: key mismatch (1Password auto-rotated mid-session), not a missing-from-agent issue; the agent asked for approval instead of diagnosing.
