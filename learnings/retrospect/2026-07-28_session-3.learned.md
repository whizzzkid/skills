## Session-3

### What worked
- Preserving individual commit SHAs by choosing a merge commit over a squash, because the plan doc and PR body cited those SHAs by hash.
- Treating each CI failure as a real defect to fix rather than a flake, which is what turned three previously-invisible bugs into fixes.

### What could've been better
- adversarial-review: batch all fix-loop remediation into a single scoped re-review after the first verdict instead of re-running the full gate per push, and honor a fatigue or waiver signal immediately.
- pr: distinguish a fix-loop push from a push carrying new unreviewed work, so the review gate does not multiply across a remediation loop.
- gh: never mark a workflow job complete, required, or documented-green until a run exists for that ref — a workflow scoped to the default branch plus pull requests never fires on a pre-PR push.
- docs: state the environment a failure was observed in before recording it as broken, and grep the whole document for every phrase the old verdict justified when correcting it.
