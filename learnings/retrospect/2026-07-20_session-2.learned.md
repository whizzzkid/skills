## Session-2

### What worked
- When a controller-rendered response is blocked by a framework guard (e.g. serving a `text/javascript` body to a non-XHR GET), serve the asset as a static file instead of fighting the guard — it is also the conventional pattern.
- Swallow a background revalidation promise's rejection with a no-op `.catch()` ONLY in the branch that already returns a cached value; leave the return-path promise able to reject so a downstream offline fallback still fires.

### What could've been better
- commit: a blanket `git add` of a generated-artifact directory swept in a stub polluted by a shared dev DB carrying another branch's migration; stage generated artifacts individually and restore model-derived stubs to base on a branch that changes no models.
