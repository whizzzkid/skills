## Session-3

### What worked
- Adversarial review caught an E2E fixture breakage (readiness probe checking a removed listener) before CI — early mechanical sweep prevented a full test-suite timeout.
- Synchronous content-script init (mount with defaults, apply settings reactively) correctly solved the panel/toolbar sync issue after two incorrect attempts.
- Renaming the manifest command to `_execute_action` correctly diagnosed the root cause of keyboard shortcuts not granting `activeTab`.

### What could've been better
- workflow: Three user corrections were not captured live via `wk-learn` — all were reconstructed during retro scan. The live-capture HARD RULE was violated at every correction point.
- workflow: Agent made two incorrect Chrome API assumptions (`sidePanel.open()` tolerates preceding `await`; `setPanelBehavior` is additive to `action.onClicked`) and shipped both without documentation verification, requiring user-reported regressions to discover.
- workflow: A fix targeting a plausible-but-wrong root cause (message-delivery polling) was shipped without confirming it addressed the user's actual symptom — the user reported no observable change.
