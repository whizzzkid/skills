## Session-13

### What worked
- Per-push adversarial-review re-gate scoped only to `git diff <cleared-sha>..HEAD` kept the review fast and idempotent across two feedback rounds.
- Reproducing a suspected test regression on the pre-change HEAD proved a request-spec failure was an environment artifact (a modern-browser guard rejecting the test UA), not a defect introduced by the diff — avoided chasing a non-bug.

### What could've been better
- wk-workflow: probe for a `.devcontainer/` before selecting a tooling environment; when the host toolchain breaks, check for a containerized alternative before repairing the host in place.
- wk-pr-resolve: re-fetch bot review threads against the just-pushed HEAD before resolving — thread node IDs and the finding set regenerate on every push, so pre-push IDs go stale.
