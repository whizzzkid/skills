## Session-2

### What worked
- Root-cause layout bugs via a live DOM assertion (Playwright/browser_evaluate) rather than re-reading the source file — the source can look correct while the render is not.
- Never trust a checked-off tracker item at face value — re-verify against the live system of record (PR/ticket state) before treating it as resolved.

### What could've been better
- sitrep: never freelance a new HTML nesting shape inside a column layout — reuse the file's own established flat-span pattern; a stray nested `<div>` silently collapses the surrounding flex layout.
- sitrep: gate any "ready"/"done" announcement on a hard verification check (DOM assertion, not just launching a browser tab) before telling the user something is fixed.
- sitrep: fold trailing "Post-Completion" instructions into the last numbered stage of a skill so they aren't skipped as an unstructured appendix.
