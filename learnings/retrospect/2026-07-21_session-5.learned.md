## Session-5

### What worked
- Multi-stage Docker isolation: compiling assets in a stage that inherits the full bundle and copying only the output into a stripped release stage keeps the release image clean while still producing artifacts.
- Post-merge verification of the PR body caught a silent corruption that reported success — verify outbound artifacts by re-fetching, never trust a tool's "updated" message.

### What could've been better
- workflow: when a fix needs config/secret values at build time, reuse the config-resolution mechanism the codebase already provides instead of inventing a parallel override (dummy env exports) — especially after the user names the existing convention; escalating pushback is a signal to abandon the approach, not defend it.
- gh: build `gh pr edit --body` payloads with a heredoc or `--body-file`, never streaming BSD `sed` `i`/`a` one-liners, which fail to parse on macOS and silently emit an empty string that overwrites the body.
