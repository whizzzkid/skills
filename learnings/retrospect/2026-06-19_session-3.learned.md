## Session-1

### What worked
- Once redirected to the correct root cause, pinning the image tag to match the project's tool-version file resolved the issue on the first CI attempt.
- Root-cause analysis (floating tag → cache invalidation → cold network fetch inside dind bridge) was precise and verifiable.

### What could've been better
- wk-docker: Agent jumped to `--network=host` without first checking whether a floating base image tag had invalidated the Docker layer cache; cache invalidation is a cheaper fix than network-flag changes in dind environments.
