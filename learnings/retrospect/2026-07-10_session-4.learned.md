## Session-1

### What worked
- Recovering a stacked PR auto-closed on base-branch deletion by recreating the deleted base ref, reopening, then retargeting to trunk — then dropping the parent's squash-duplicated commits with `git rebase --onto <trunk> <old-base-tip> HEAD` so the diff collapses to only the child's own changes.
- Folding a review bot's findings and the fresh adversarial subagent's residual suggestion into the same fix before pushing, rather than shipping the partial guard.

- pr-resolve: did not detect the stacked-PR-closed-on-base-delete state up front; recovery was improvised (routed to wk-learn).
- gh: retried a flaky `gh pr edit --base` GraphQL 500 several times before switching to the REST PATCH path (routed to wk-learn).
