## Session-1

### What worked
- For auth-boundary changes, drive the anonymous flow in a real browser with no session, which surfaces background-fetch breakage that request specs miss.
- Mutation-check new auth tests by temporarily restoring the removed guard and confirming they turn red.

### What could've been better
- commit: Never pipe a lint or test gate before `&& git commit`; capture its exit status first.
- docker: Diagnose a failing devcontainer overlay build with a trace log before guessing, and lowercase the compose project name for teardown.
- gh: Check for an existing pending review before posting a REST reply, and resolve threads only after the reply lands.
- workflow: Capture tool-specific surprises live when they happen, not at retro.
