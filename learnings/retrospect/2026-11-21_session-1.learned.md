## Session-1

### What worked
- A single source-of-truth pin read by one shared install script, with an assert that the installed version matches the pin, removed the drift between images and hosts with no second copy to maintain.
- Mutating a saved copy and restoring it with `cp` + `cmp` proved that each new rejection test kills its mutant, without touching VCS.

### What could've been better
- git: stacking on an open PR branch needs `git switch -c <new> origin/<pr-branch>`, not a rebase; a rebase replays base commits the parent PR lacks.
- buildkite: watch loops must pass a full SHA to the commit filter and cap repeated "none" polls.
- gh: a pending self-review blocks REST thread replies with a 422, so check for it before replying.
- pr: issue-tracker URLs are identifiers too, so resolve them from a command before writing a PR body.
- workflow: live capture missed three self-caught errors (the guessed tracker host, the short-SHA watch, the pending-review 422); invoke wk-learn in the response that catches each one.
