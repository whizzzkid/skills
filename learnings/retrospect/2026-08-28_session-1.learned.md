## Session-1

### What worked
- Bot review rounds converged cleanly by fixing the finding in code and resolving the thread, never escalating the gate before the fix landed.

### What could've been better
- workflow: When adding client-side controller logic with branches unreachable by server-rendered request specs (id collision/suffixing, fragment parsing), extract the pure logic into a DOM-free module with unit tests up front, rather than waiting for a test-scope review finding to force the split.
- workflow: When new helper logic needs a grammar/contract an existing module already owns, import from that single owner instead of forking a parallel copy — a fork is a module-boundaries finding waiting to happen.
