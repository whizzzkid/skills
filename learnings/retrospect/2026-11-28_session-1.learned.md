## Session-1

### What worked
- Launching the pre-1.0 and transitive-major changelog audits as a background workflow while the container built hid the audit latency and surfaced the vendored-loader regeneration before the first push.
- Rerunning a lone failing spec with each forwarded config-override env var unset proved the failure environment-induced without bisecting any bump.

### What could've been better
- renovate: When Step 4 finds any major-class bump, run the adversarial review before marking the combined PR ready, because a user can enable auto-merge on the draft and merge it on green CI before the post-ready gate fires.
- renovate: Step 3 should say that a scoped `bundle lock --conservative --update` routinely resolves newer than the advertised version, so pin-and-verify each package immediately instead of discovering the overshoot in the diff.
