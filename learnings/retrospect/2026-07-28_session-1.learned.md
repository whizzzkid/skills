## Session-1

### What worked
- Adversarial verification (mutation testing + property-based simulation) caught real, non-obvious gaps in a pruning feature's test coverage and design-doc claims before they reached review comments.
- Detecting a moved PR head mid-review (new commits landed on the branch) and re-pulling before posting stale-line comments avoided posting comments anchored to superseded code.

### What could've been better
- wk-adversarial-review: empirical-pass verification re-ran the full spec suite/directory (and 20 full-suite mutation cycles) instead of scoping runs to only the changed method's spec examples, wasting significant time on a small diff when CI already covers full-suite regressions.
- wk-pr-review: after the user gave process feedback unrelated to the in-flight action, the agent stopped instead of completing the already-approved pending action (posting the prepared review), requiring the user to explicitly prompt it to finish.
