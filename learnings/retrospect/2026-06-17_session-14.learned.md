## Session-1

### What worked
- Adversarial subagent caught a tautological env-var fallback test before push: both-unset and partial-unset tests collapsed to the same URL assertion because the test harness already supplied the script's own default value. Fixing one test to use a non-default explicit value made each case independently observable.

### What could've been better
- wk-testing-skeleton: In fake shell-binary scripts that shift args in a `while [[ $# -gt 0 ]]` loop, `echo "$@"` placed after the loop always emits nothing — the loop consumed all positional args. Capture values during the loop (e.g. `api_url="$1"` in the wildcard branch) so they survive after the loop ends.
