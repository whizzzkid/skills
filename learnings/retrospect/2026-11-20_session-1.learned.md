## Session-1

### What worked
- Diffing the combined lockfile against base for every major, including transitive ones, caught bumps that no PR title named.
- Rerunning a lone failing spec with forwarded config-override vars unset separated an environment-induced red from a dependency regression.

### What could've been better
- renovate: regenerate a Dependabot lockfile scoped to the named packages and pinned to the advertised versions, instead of cherry-picking it wholesale.
- devcontainer: capture only the tail of `devcontainer up` output, because the resolved compose config echoes forwarded secrets.
- adversarial-review: verify environment facts (installed versions, fixtures) with a command before stating them in a reviewer brief.
