## Session-1

### What worked
- Running parallel research agents with narrow briefs, then an independent adversarial agent given only the diff,
  caught security overclaims that self-review missed.
- Generating the shared-doc variant from the repo markdown with a script (absolute links, diagrams swapped out)
  keeps the doc and the spec in sync across revisions.

### What could've been better
- arch-review: verify the primary source behind subagent-reported security claims before the draft is complete.
- arch-review: meeting notes are leads to validate, never citations or quotes; capture this the moment the user says it.
- workstyle-shell: avoid zsh-tied variable names like `path` in ad-hoc loops.
