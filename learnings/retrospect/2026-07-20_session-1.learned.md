## Session-1

### What worked
- Investigation-before-code: tracing an alert to the exact failing endpoint/status via metric grouping + access logs pinpointed the root cause before touching code.
- A single choke-point (shared base-controller render helpers) covered every reject path with one small change rather than per-controller edits.

### What could've been better
- workflow: when a prompt bundles multiple deliverables (e.g. "implement X, produce doc Y"), confirm ordering up front — the user reordered mid-flow to want the doc first; enumerate deliverables AND their sequence before starting the first.
