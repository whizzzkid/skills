## Session-2

### What worked
- Parallel worktree dispatch (3 agents, 3 independent PRs, ~13 min wall clock) scales well for independent UI fixes — read all source files before briefing so agents have full context and self-correct coordinator mistakes
- Manual worktree creation + agents with Bash access (not `isolation: "worktree"`) is the correct pattern when agents need shell for tests/commits/PRs

### What could've been better
- [wk-workflow]: when briefing parallel agents on CSS/design-token work, always read and quote the actual token declarations from the stylesheet — never assume names from convention (agents self-corrected, but the brief was wrong)
