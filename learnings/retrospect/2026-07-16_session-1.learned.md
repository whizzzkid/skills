## Session-1

### What worked
- Failing closed on a fail-open client (rescue-all, nil on failure, no raise into the caller) plus a per-item inline rescue isolates one malformed record without collapsing the whole batch.
- Extracting near-identical transport code into one shared helper and proving via truth-table/strictness analysis that the consolidated guard is a strict superset of every original's rejections before replacing them.

### What could've been better
- gh: `gh pr checks --watch` can exit on partial resolution; re-confirm the full statusCheckRollup is terminal before declaring CI green.
- jira: a ticket key inherited from the branch/commits may reference unrelated work — verify the ticket summary/component matches the diff before tagging the PR with it.
