## Session-4

### What worked
- Coordinator pattern for worktree-isolated agents: agents handle Read/Edit/Write, coordinator handles Bash/commit/PR/merge — effective adaptation when isolation blocks shell access.
- Research-first planning with an Explore agent gave complete file/line/CSS context before any edit, eliminating false starts.
- Parallel dispatch of 3 independent worktree agents cut wall-clock time to roughly 1x instead of 3x sequential.

### What could've been better
- workflow: The full adversarial-review gate was overkill for simple CSS/routing fixes; the user correctly redirected to "just mark ready." Skill should recognize low-complexity diffs and skip the heavy gate unless explicitly requested.
- workflow: Agents wrote comments with non-ASCII characters (em dashes) that RuboCop's Style/AsciiComments flagged — agents should run lint checks themselves or the coordinator should lint before committing.
