## Session-N

### What worked
- Splitting a PR mid-flight (models-only, deferring the dual-write contract to a new part) kept each stacked PR small and independently reviewable — honor the no-large-PRs directive by carving scope out as soon as it grows, not at review time.
- When a tooling script returns a nonsensical result, fall back to independently-verified ground truth (known merge-base + stated stacking target) instead of blocking on or trusting the broken output.

### What could've been better
- wk-pr: base-detection loop can silently return its sentinel default when the true base is a local-only stacked branch; treat an unchanged sentinel distance as detection failure, not a valid "base = default".
