## Session-2

### What worked
- Classify an alerting error as handled vs unhandled from the span's error-handling tag and the sibling spans in the same trace before designing a fix; it reframes "outage" as "telemetry noise from a known race".
- Prove every new regression test red against a deliberately defeated fix before trusting it green.

### What could've been better
- workflow: when a new step consumes an input earlier than the existing validation, list which guards have run at that line before asserting any bound in code or comments.
- workstyle-testing: a thread-race spec needs a bounded rendezvous at the check step; a start barrier alone leaves the race window closed.
- learn: a self-caught vacuous test was captured only at retro; capture it in the response where the negative control fails.
