## Session-6

### What worked
- For a "formatting-only, no behaviour change" claim, compare position-stripped parse trees of base and head. An expected structural change serves as the negative control.
- When the project formatter's style conflicts with the repo convention, run the convention's own formatter on scratch copies as the oracle.

### What could've been better
- commit: never end a turn between commit and push, or between first push and PR creation, when the workflow authorizes them.
- find-cli: resolve a package's install dir before searching; never search from the filesystem root.
- self-review: run payload edits and the POST that reads the payload one after the other, never in parallel.
- workstyle-docs: before writing a code comment that makes a factual claim, check the claim against source.
