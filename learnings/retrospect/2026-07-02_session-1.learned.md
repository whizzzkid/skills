## Session-1

### What worked
- Lifting a shared reader into a common lib before extending it (prefactor) keeps the untouched consumer byte-identical and matched a decision already recorded in an ADR.
- Composing a credentials file in a temp file then swapping with a single `mv` gives an atomic write and inherits `mktemp`'s restrictive permissions for free.

### What could've been better
- workflow: never gate a correctness claim on the exit status of a piped command (`cmd | tail` returns tail's status) — capture the target command's own `$?` via redirect, or check `PIPESTATUS`.
- workflow: run the full CI-mirroring check before claiming "lint clean" — a pre-commit hook that globs only `*.sh` silently skips other linted file types (e.g. `.bats`) that the full check enforces.
- testing-skeleton: an unquoted leading `~` inside a bash `[[ =~ ]]` regex is tilde-expanded to `$HOME` before matching — assert literal tilde strings with a quoted glob (`== *'~'*`, quoting any tilde-prefixed path segment), not a regex.
