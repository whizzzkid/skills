## Session-1

### What worked
- Documenting exclusion invariant in AGENTS.md prevents future agents from re-adding the problematic file to SOURCE_ROOTS — good pattern for encoding architectural decisions at the point of enforcement.

### What could've been better
- [wk-pr]: Follow-up PRs in the same session were not rebased on latest remote main after prior PRs merged, causing stale base and unnecessary diff noise.
- [wk-workflow]: Agent built additive complexity (new CLI commands, API workarounds, gate-splitting) across 3 PRs before considering the simplest solution (exclusion). Prefer subtractive/exclusion-based fixes before additive machinery.
