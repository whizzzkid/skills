## Session-3

### What worked
- Background CI-wait pattern (polling checks with jq until all non-pending) avoided idle loops and let agent batch other work while waiting
- Fleet-grep validation (checking 3-4 sibling repos for the same integration) quickly confirmed the correct auth pattern — should be a standard first step, not a user-prompted fallback
- React + reply + resolve loop for bot review findings became an efficient steady-state workflow once the ordering was established

### What could've been better
- workflow: Agent speculated fixes for shared-gem integrations without checking how sibling services implement the same pattern — user had to explicitly redirect to "grep other repos"
- workflow: Pushed code failing linter checks at least 3 times — should run project linter on changed files before every push
- workflow: Dropped an explicit user request (create rubocop pre-push follow-up PR) without tracking or surfacing it at session end
- pr-resolve: Resolved a review thread via GraphQL without first implementing the code fix — user caught it and had to re-block the PR
- gh: Used emoji characters in comment text instead of GitHub's native reactions API endpoint
