## Session-1

### What worked
- On cross-language contract changes, dispatch an adversarial subagent — it catches blockers (flag propagation, silent-disable) that mechanical sweeps miss.
- Extract inline logic into a named helper before the test pass; refactor-then-test makes the logic directly testable.

### What could've been better
- wk-workflow: enforce the documentation requirement at every commit boundary, not as a deferred end-of-session step.
- wk-workflow: adversarial review + PR creation are mandatory after implementation — never stop at "commits landed" without an explicit pause request.

## Session-2

### What worked
- `git rebase --onto <base> <tip-of-merged-branch>` isolates local commits from already-merged base commits in one step.
- Fetch all three comment surfaces (inline, review bodies, issue comments) up front — inline-only fetch misses bot findings.

### What could've been better
- wk-adversarial-review: add an upper-bound sweep for numeric security-gate fields (grep `Max`/`Threshold`/`Limit` lacking a ceiling constant).
- wk-adversarial-review: extend the comment-accuracy sweep to flag `only`/`never`/`must` claims with no pinning test.
- wk-adversarial-review: add a check for pass-through wiring in entrypoints that lacks an integration test.
- wk-pr: check open-PR diffs for an existing related spec before creating a new spec doc.
