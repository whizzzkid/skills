## Session-N

### What worked
- Distinguish a regression from noise with concrete evidence before dismissing it: isolate the failing test with a fixed seed, compare a failing check against the base branch's latest run, and check a hook's target-file list — never assume "not mine."
- Mirror an existing codebase pattern (strict `Integer(raw)` + rescue + warn) when fixing a class of bug, rather than inventing a new one, so the fix reads as native.
- On the guard/approval path, cap last so the safety ceiling always wins, and cover the kill-switch and min==max edge cases with explicit tests.

### What could've been better
- wk-workflow: announce expected duration before any >~1 min operation (full suite, CI poll, repeat flake runs) so normal latency does not read as a hang.
