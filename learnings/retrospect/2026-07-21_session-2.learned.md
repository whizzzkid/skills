## Session-N

### What worked
- Reviving a stale branch by `git rebase --onto origin/<default> <last-base-commit> HEAD` cleanly dropped the already-merged base commits, leaving only the feature delta.
- Re-running the adversarial gate on revive caught a real blocker the original review missed (unscoped query surfacing convergent-duplicate rows) — never trust a prior clearance across a rebase.

### What could've been better
- pr: a CLOSED PR whose base branch was deleted (squash-merged parent) cannot be reopened or retargeted via the API — detect this up front and create a fresh PR to the default branch instead of attempting `gh pr reopen`/`gh pr edit --base`.
