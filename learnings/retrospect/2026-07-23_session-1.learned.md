## Session-1

### What worked
- Editing a file on a remote branch of an out-of-scope sibling repo via the host Contents API (GET sha+content -> decode -> edit -> PUT with prior sha) avoids needing a local checkout when a scope guard blocks the path.
- Renaming a numbered sequence across a doc via high-to-low substitution (N->N+1 starting at the largest) prevents the cascade a low-to-high pass would cause.

### What could've been better
- workflow: when the user asks to gather decisions "1-by-1" AND to "collect all decisions first", treat decision-collection as a distinct phase that fully completes before any execution begins.
- workflow: "update the plan/doc to mark items done" means editing the artifact's body, not posting a comment about it.
