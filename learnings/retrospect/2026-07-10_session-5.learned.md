## Session-5

### What worked
- Adversarial review before the push gate caught a non-hermetic test (an unstubbed collaborator writing to the same observability sink) that green specs had hidden.
- Dismissing a performance finding with a correctness rationale (fresh per-request reads enable on-the-fly credential rotation) beats silently caching to satisfy the finding.

### What could've been better
- wk-testing-skeleton: an `expect(...).to receive` assertion carries an implicit `.once`; when the method under test invokes the sink once per iterated key it false-fails, so assert `.at_least(:once)` (or an explicit count) whenever the call fans out over multiple inputs.
