## Session-1

### What worked
- Deriving CalVer from git commit timestamp (not wall-clock) for retry determinism — solved the Cloudsmith 409 idempotency constraint cleanly and without revisiting the decision.
- Parallel CI fix loop: each failing spec surfaced a root cause (fake git missing handler, macOS BSD `date`, glob over-match) that was independently diagnosable and fixable without touching passing tests.
- Cross-language contract locked by a stamped binary test: building the binary with `-ldflags "-X main.BuildVersion=stamped"` and asserting output is the only reliable way to verify the shell→Go symbol name; a string-match on the flag value is insufficient.

### What could've been better
- bash: Using `:?` as a guard clause in scripts that also register EXIT traps — bash 3.2 silently resets the exit code, making the guard a no-op. Explicit `if [[ -z ]]; then exit 1; fi` is portable and trap-safe.
- buildkite: After a push, announcing "monitoring in background" without sharing the build URL or the failing step — user had to interrupt to learn what the agent was investigating.
