## Session-3

### What worked
- Empirically verify framework navigation semantics in a live app before shipping (a link attribute that "should" work can silently downgrade behavior); a small survival-token check settles it in minutes.
- Extract a shared helper the moment a review finds the same nil-guard/display pattern repeated across three registries — one module plus a matrix spec replaced four duplicated procs.
- Superseding a permanently auto-closed stacked PR with a fresh PR from the same branch (after merging the default branch) is a clean recovery — no history rewriting needed.

### What could've been better
- pr: default draft-until-CI-green conflicts with repos where an automated review bot approves only ready PRs — mark ready immediately when the bot gates on ready state (routed to wk-learn).
