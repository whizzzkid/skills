## Session-1

### What worked
- Regenerating a single spliced artifact from per-module source + a build script kept a large generated file reviewable and each fix atomic.
- Briefing the adversarial subagent with the artifact's specific lifecycle contracts (not a generic pass) surfaced only real defects with no false positives.
- Cross-checking a subagent's mislabeled finding against actual file contents before acting avoided a wrong fix.

### What could've been better
- wk-workflow: the plan-approval gate slipped on a large/exciting build — state it as size-independent in both directions (neither too-small nor too-big-and-clear waives it).
- wk-pr: PR body shipped with the commit-trailer footer instead of the canonical wk-gh outbound footer — inject the correct outbound footer at PR-body render time, same as review comments.
