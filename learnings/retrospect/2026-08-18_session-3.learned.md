## Session-3

### What worked
- Capturing a before/after pair by stashing the change, rebuilding, and reading computed styles back from the browser turns a visual CSS claim into a verifiable one.
- Recording the invariant a diff just fixed into the spec paragraph nearest the enforcing code, so the next agent reads the correct edge before flipping it back.

### What could've been better
- self-review: staging the pending review before the adversarial-review gate guarantees anchor rot when findings produce commits — stage it after the finding-response commits, or expect a delete-and-re-stage cycle.
- workflow: the phase order puts self-review before publish and adversarial review after ready, so on any PR whose review yields fixes the self-review anchors are stale by construction; the ordering needs an explicit re-anchor step rather than leaving it to the updating-an-existing-self-review path.
