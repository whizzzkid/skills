## Session-5

### What worked
- Adversarial review of a first-draft rule change caught an over-suppression conflict with an existing finding category before publishing; running it on prose/instruction diffs pays off.
- Reproducing a CI spec failure locally before diagnosing correctly classified it as infra-flaky, avoiding a wasted diff bisect.

### What could've been better
- workflow: when a false positive stems from an unverifiable claim class, propose suppressing that class, not a broad severity downgrade -- severity changes are for real-but-overweighted findings.
- workflow: a user correction during the proposal phase did not get a live wk-learn capture; it was reconstructed at retro (capture-control failure).
