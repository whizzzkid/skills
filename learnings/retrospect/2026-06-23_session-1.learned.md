## Session-1

### What worked
- Adversarial review caught two blockers early (wrong location for a dependency-enforcement rule, contradictory downgrade-to-info rule) — invoking the review before PR creation prevented wasted iteration
- Codifying the no-shell-commands constraint in the external review tool's check-authoring config files prevents future authors from making the same mistake
- CI polling via background task freed up main loop to continue with other work

### What could've been better
- External review tool: Included shell command (`ruby -e ...`) assuming execution environment capabilities that don't exist — the agent has only Read, Glob, Grep tools. Use Glob(pattern) instead.
- wk-pr: Did not wait for new CI run to complete before marking PR ready after the final push (corrected immediately after user question, but should have been automatic)
- Review tool check-authoring guide: Missing explicit rule against shell command invocations in check bodies — added now, but should have been in place
- Review tool check config: Same — no prior constraint on executable code in check bodies
