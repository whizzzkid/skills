## Session-1

### What worked
- Triaging all bot findings before applying any fix prevented unnecessary fixes on false positives and already-addressed findings.
- GraphQL thread node IDs for resolve operations proved stable; REST comment IDs for bot reviews 404 on re-reads but node IDs don't.

### What could've been better
- wk-buildkite: When the same infra-level CI error repeats across multiple rebuilds, stop diagnosing instead of escalating to exhaustive job listing.
- wk-gh: Use `/replies` subresource for inline comment replies rather than `in_reply_to` field — field formatting causes 422.
