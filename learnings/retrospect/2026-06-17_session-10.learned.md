## Session-10

### What worked
- Playground validation correctly separated two adversarial findings: a real git checkout abort (dirty tracked file) from a fabricated one (no-op on git show failure is correct bootstrap behavior). Without independent sandbox runs, both could have been accepted or both rejected.
- Capturing `computed_state` before `git restore` + checkout, then writing it back post-checkout, is the correct sequence for "commit state that differs from what HEAD + origin/main both contain."

### What could've been better
- adversarial-review: adversarial claims about "missing error-path writes" need a concrete failure scenario before rating as blocker -- absence of defensive code is not itself a correctness defect when the no-op IS the correct behavior.
