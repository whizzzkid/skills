## Session-1

### What worked
- Running an external review CLI and the adversarial subagent in parallel during the final gate: both tools independently surfaced the same test-coverage gap, providing convergent evidence without extra latency.
- CI polling via `ScheduleWakeup` instead of blocking the turn — no turn wasted on a 5-minute build.
- Collapsing nearly-identical nil-tier tests into a parameterized `each` block in response to an adversarial finding; the adversarial subagent also later validated a third case (garbage tier.txt) fits the same pattern.

### What could've been better
- [adversarial-review]: Ruby diffs with non-ASCII comment characters (em-dash) should be swept for `Style/AsciiComments` violations before the CI fix loop; add a grep for `[^\x00-\x7F]` on new `+` comment lines when the repo runs RuboCop with this cop enabled.
- [workflow]: An external review CLI's flag is `--repo-path`, not `--repo`; a global instruction hard-codes the wrong flag, causing an immediate exit-code-2 failure on first invocation.
