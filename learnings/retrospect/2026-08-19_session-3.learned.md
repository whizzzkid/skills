## Session-N

### What worked
- A deliberately-scoped quick review sweep (single mid-tier model) caught a real latent bug (copy-vs-rename status folding a copy into a deletion) that a full adversarial panel was waived from finding — a cheap targeted sweep is a valid substitute when the user waives the full gate.
- Empirically refuting a bot reviewer's false positive in a throwaway repo (git -z rename emits target-then-source) beat both blindly implementing and blindly dismissing the suggestion.
- Correcting a malformed user-supplied fix snippet (invalid sed replacement, targeting only the legacy sources path not the DEB822 layout) rather than applying it verbatim.

### What could've been better
- wk-gh: never assert a PR is merge-blocked on branch-freshness from a BLOCKED merge-state alone; read the ruleset and confirm the strict require-up-to-date flag is actually set.
- wk-self-review: at the merge gate, detect still-pending self-authored reviews and submit (or surface) them instead of leaving design notes as invisible drafts the user must chase.
