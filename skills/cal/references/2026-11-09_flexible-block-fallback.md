**Rule** — When no window is free for the full scorecard duration, propose the earliest full-duration slot that
overlaps only flexible blocks (no other attendees; auto-placed or marked habit / focus time), naming each block in the
warning. Book it only on user confirmation and never shorten the block; the busy definition itself is unchanged.

**Why** — An interview followed by a meeting and a multi-hour auto-scheduled habit block left no free 45-min window,
so the scan emitted a bare warning. The busy rule draws no line between fixed meetings and self-only blocks the user
would readily displace, so a packed day yielded no option at all.

**Rejected** — Auto-booking over the flexible block: it relaxes the every-non-declined-event-is-busy guard and moves
the user's time without consent. Proposing keeps the guard intact.
