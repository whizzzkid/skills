# Live capture precedes task continuation

**Rule** — Corrections, scope redirects, and self-caught errors trigger
`wk-learn` in the response where they occur, before active task work resumes.
The retro verifies and promotes prior capture; it does not reconstruct a batch.

**Classification** — `already-covered (unshipped)`. The baseline same-response
capture and retro-verification rules predated this report. A sibling learning
from the same incident already escalated that baseline to `**Important:**` and
made the continuation boundary explicit, but that strengthening landed after
this report and earns no additional notch here.

**Coverage** — `SKILL.md` → Mandatory Activation → live learning capture, and
`README.md` → Noteworthy → live learning capture.
