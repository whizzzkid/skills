- **Rule**: After issuing a backgrounded watch, return control immediately with a concrete next step — never close the turn announcing a holding pattern.
- **Why**: A "watching CI, will continue when green" sign-off blocks the user, forcing a re-prompt to resume — defeats the purpose of running in background.
