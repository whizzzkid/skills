- **Rule:** When the prompt lists ≥2 distinct, independently-shippable
  deliverables, ask "one PR or separate?" before planning.
- **Why:** A bundle of N tasks reads as a clear requirement but hides a
  granularity decision only the user can make — planning all N in parallel
  invites a mid-flight scope reset.
- **Where:** Phase 1, "Multi-deliverable scope probe" (distinct from the
  acceptance-criteria / scope-boundary grills).
