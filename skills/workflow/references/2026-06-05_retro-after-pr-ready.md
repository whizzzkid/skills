- **Rule:** After every `gh pr ready` succeeds, the next action is
  `Skill(wk-retro)` — no prompt, no asking.
- **Why:** Marking a PR ready feels like a session terminus, so the
  mandatory retro gets dropped. "Work is done" != "workflow is done".
- **Where:** Phase 8 (Session Retro) — `gh pr ready` is not a terminus
  HARD RULE.
