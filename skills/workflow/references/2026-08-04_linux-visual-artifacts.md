# Review platform-pinned visual baselines from CI artifacts

**Rule** — For a visible change with platform-pinned baselines, inspect the CI artifact's actual, expected, and diff
images. Replace only snapshots that confirm the intended change.

**Why** — Review screenshots and test baselines can use different platforms and serve different purposes.

**Where** — Phase 3.6 frontend live preview and visual verification.
