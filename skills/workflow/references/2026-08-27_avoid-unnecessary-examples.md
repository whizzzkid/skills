# Prefer smallest general rule over specific examples

**Rule:** When a focused check or guardrail rule addresses the reported
behavior, prefer the smallest general formulation. Include a concrete
implementation example only when the general rule alone cannot enforce correct
behavior.

**Why:** A prior edit carried more incident detail than the durable guidance
required — the specific example was not needed for the safeguard to function.

**Already covered by:** wk-sharpen Core Rule ("Extract Principles, Not
Examples") and Style Rules ("Instructional, not explanatory"). No wk-workflow
SKILL.md edit needed — the principle governs how rules are authored (sharpen
domain), not workflow execution.
