- **Rule** — Batch mode processes every unprocessed learning one-by-one with
  no per-run cap; severity only sets order, not a stopping point.
- **Why** — A fixed cap (the old "process 5, report the rest") orphans the
  remaining learnings indefinitely, lets the inbox grow unbounded, and defers
  their lessons so the source incidents recur.
- **Where** — Source 2 (Repo learnings directory) in the Batch Mode section.
