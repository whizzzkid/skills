**Rule:** When tight headroom forces a reclaim, the reclaim target's *combined*
measured size must strictly exceed the drafted rule — not merely "be sized." A
single relocated block routinely undershoots a multi-clause HARD RULE or wide
row, so default "one block out, one rule in" to net-positive and budget ≥2
reclaims (or a relocation + why-to-references trim) up front.

**Why:** Picking a reclaim target by size feel without measuring the drafted
rule first lands net-positive on a multi-clause rule, forcing a second
relocate/trim pass — the exact re-violation the measure-exactly-once rule warns
against.

**Where:** Step 7.5 — "Budget the reclaim before drafting when headroom is tight."
