- **Rule:** "Make a learning" / "capture this" / "note this" routes to `wk-learn`; only "sharpen the skill" / "apply this to the skill" / explicit `/wk-sharpen` authorizes `wk-sharpen` to rewrite `SKILL.md`.
- **Why:** Direct skill edits without explicit consent overwrite a shared repo; the user requires capture-first, distill-later.
- **Where:** "When to Use" section HARD RULE on invocation routing.
