# Reference-file template

**Rule** — write one short reference file per learning under
`skills/{name}/references/`. Create the directory if missing.

## Frontmatter

- `class: principle` or `class: one-off`

## `principle` files

- **Rule**
- **Why**
- **Where**

## `one-off` files

- **Scenario**
- **Symptom**
- **Fix**
- **Why not promoted**

**Why** — a fixed field set makes a later pass able to tell a distilled principle
from a parked one-off without re-reading the original incident.

**Where** — `SKILL.md` → Step 7 → *Write distilled references*.
