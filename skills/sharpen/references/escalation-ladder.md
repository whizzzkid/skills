# Re-violation escalation ladder

**Rule** — escalate a re-violated rule by exactly **one** rung per fresh learning.
Never jump rungs; never escalate without recording the bump in the reference file.

1. baseline prose rule
2. `**Important:**`
3. `**Very important:**`
4. `**CRITICAL:**`
5. `**HIGH-PRIORITY:**`
6. `**HIGHER-PRIORITY:**`
7. `**VERY-HIGH-PRIORITY:**`
8. restructure the section so the rule is structurally impossible to skip

**Why** — a label already at its ceiling has no signal left to add; the only
remaining move is structural. Jumping rungs burns the ladder's headroom on one
incident and leaves later re-violations nothing to escalate to.

**Where** — `SKILL.md` → Step 3 → *HARD RULE: re-violation escalation*.
