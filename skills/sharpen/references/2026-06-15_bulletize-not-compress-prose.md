# De-bloat by bulletizing, not by compressing prose

**Rule:** The de-bloat pass converts prose into terse, crisp bullet points and
checklists — one rule per line, imperative voice, `→` for causality, articles and
connectives dropped in procedural text. Do not merely shorten sentences; compressed
prose still reads as prose and resists scanning. State each rule once and
cross-reference rather than restate.

**Why:** A de-bloat that only tightens sentences keeps the prose shape, so the file
stays hard to scan and barely shrinks. Bulletized structure is what makes a runtime
instruction scannable and dense, and it cuts far more bytes toward the 24 KiB
ceiling. Also encoded in `AGENTS.md` → "SKILL.md Prose Style".

**Where:** Step 7.5 De-bloat Pass → "Bulletize, do not compress prose."
