**Rule:** A repeat of an existing rule is escalation evidence only when the rule *failed*. Before escalating an `already-covered` repeat, check for same-session positive-steering evidence (a retro "What worked" bullet, or the learning conceding the existing behavior was correct). If present, classify `already-covered`, cite the proving lines, and do NOT escalate.

**Why:** The re-violation escalation rule infers "rule not steering" from a repeat. That inference only holds when the rule failed. Positive steering evidence is the opposite signal — the rule fired correctly; escalating would inflate a rule that needs no change.
