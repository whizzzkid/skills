- **Rule:** A claim that an external dependency/plugin supports a feature must
  link the upstream source file/line or official docs proving it — at
  composition time, not after a reviewer challenges it.
- **Why:** Hard Rule 4 scoped "implementation" to the repo's own source; a
  claim about an external tool's capability has its proof outside the repo,
  so the rule did not compel citing it — leaving external-capability claims
  unsupported until challenged.
- **Where:** Hard Rule 4, third sub-paragraph (external-capability claims).
