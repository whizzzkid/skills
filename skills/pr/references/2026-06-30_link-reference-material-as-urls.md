- **Rule:** "Link the reference material" (and similar reference/citation
  requests) means add the source URL to the PR body. Never copy referenced files
  into the repo to satisfy it. Ambiguous reference request → clarify scope before
  creating any files.
- **Why:** "Link" was read as "make locally available", so the agent copied files
  into the repo instead of citing by URL. A reference request is not authorization
  to create files.
- **Where:** Step "Link the source plan and spec (pre-flight)".
