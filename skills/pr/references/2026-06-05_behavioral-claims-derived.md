- **Rule:** Derive PR-body behavioral claims (rules, conditions,
  thresholds, severity) from the implementation — re-read the source and
  verify each claim verbatim; never narrate from intent.
- **Why:** Paraphrasing from memory drops qualifiers (e.g. a scope word
  like "project-wide"), making a blocker condition look broader/narrower
  than the code enforces — wrong from the first draft, not via drift.
- **Where:** Hard Rule 4 (derive behavioral claims, never narrate).
