- **Rule:** When `.md` files appear in the PR diff, append a `## Previews` section to the PR body with a rendered-preview link per file.
- **Why:** Reviewers can open the formatted view alongside the diff instead of mentally parsing raw markdown.
- **Where:** New "Markdown preview links" sub-section in Step 2 ("Create Draft PR"), before Step 3.
