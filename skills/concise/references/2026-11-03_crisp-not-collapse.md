# "Crisper" trims wording inside the existing structure

- **Rule:** Treat "make it crisper / less wordy / tighten" on a draft as a compress: keep every section, bullet, and
  fact; cut filler and duplicate clauses (~15–20%). Confirm before any larger cut, merged section, or structural
  change.
- **Why:** Asked to make a long draft less wordy, the agent cut ~60% and merged sections and bullets; the user
  interrupted and asked for the previous format back. A wording request was read as a length-and-structure request
  without confirming the target. `/concise:compress` already preserves heading and bullet structure; the
  natural-language request did not inherit that.
- **Where:** [`wk-concise`](../README.md) → `/concise:compress` section. Filed against `wk-sitrep`; rerouted to the
  owner of prose compression.
