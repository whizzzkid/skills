- **Rule:** Each standup bullet carries at most one `<url|text>` link; groups become a label parent bullet with one child bullet per artifact.
- **Why:** Multiple links per line produce visual noise in Slack and make individual items hard to click; supersedes the prior "N space-separated links on one line" rule.
- **Where:** Standup snippet → Source-link enforcement (HARD RULE: One link per bullet) + format template's nested group example.
