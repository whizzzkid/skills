- **Rule:** A PR qualifies as a Yesterday standup bullet only if the user is the author, listed co-author, or primary/approving reviewer who drove it.
- **Why:** Merging another person's PR is a maintenance action, not an achievement; claiming it misrepresents authorship to the team.
- **Where:** Standup snippet "Source mapping" → Yesterday bullet HARD RULE.
