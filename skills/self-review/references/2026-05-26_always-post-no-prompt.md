- **Rule:** Post the pending self-review immediately after Step 3's summary. Never ask "want me to post this?" — the pending review is a draft; GitHub's Submit button is the human checkpoint, not a terminal prompt. The user can opt out before the summary is presented ("don't post" / "wait" / "let me edit first").
- **Why:** Agent gated posting behind user confirmation, adding an extra round-trip for a draft action that is already gated by the GitHub Submit UI. Matches the same pattern fixed in wk-pr-review Phase 6 (2026-05-26).
- **Where:** Step 3 HARD RULE — "never ask 'want me to post this?'"; Step 4 opening line — "Post the pending review immediately after Step 3's summary — no approval prompt."
