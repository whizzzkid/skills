- **Rule:** On an approach pivot, audit unresolved self-review threads on
  the changed files independently of any new proposed comment; resolve those
  whose rationale describes the old approach and repost anchored to the new
  commit.
- **Why:** Step 2.5's stale-resolution only fires when a new overlapping
  comment is processed — a pivot can leave a thread silently contradicting
  the new code with no new comment proposed.
- **Where:** Step 2.5, "Approach-pivot thread audit".
