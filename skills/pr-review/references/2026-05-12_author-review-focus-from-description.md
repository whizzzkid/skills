- **Rule:** Parse the PR description for explicit author asks ("Review focus", "thoughts on X?", "not sure about Y") and answer every captured item across Phases 3–5.
- **Why:** A review that ignores the author's stated questions misses the highest-signal feedback opportunity and forces a second round.
- **Where:** Phase 1 → "Extract author review focus from the PR description"; Phase 5 → "Answer author review-focus items".
