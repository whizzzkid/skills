**Rule:** Render every evidence-backed review claim with an explicit agent stem —
"My agent verified/simulated/ran `<X>` and found `<Y>`" — never a bare "I verified".
Reserve bare first-person for the human's own posture ("Approving with concerns").
Applies to inline comments and the review body.

**Why:** The reviewer posts on the user's GitHub identity; a bare "I verified X"
reads as the human personally vouching for a check they did not run, so the reader
cannot tell a machine-validated claim from a human judgement — misattributing
accountability.

**Where:** wk-pr-review Phase 4 comment format (HARD RULE), carried into Phase 5
body.
