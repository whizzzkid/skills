# Approve-with-concerns posture; encouraging, non-robotic voice

- **Rule** — Default to approving with concerns the author resolves, not
  blocking. Never use "blocker" in author-facing text; use "concern" /
  "limitation". Sound encouraging, and when concerns are many, add one
  affirming line ("Everything here is fixable — don't fret it").
- **Why** — The reviewer rarely blocks; "blocker" language and a robotic,
  terse-only voice discourage the author and misframe the verdict.
- **Where** — New "Review posture" subsection + reworked "Tone" in Phase 5;
  `concern:` replaces the `blocker:` severity prefix throughout; affirming
  line lives in the Phase 6 review body.
