**Rule:** A substantive new finding gets its own line-anchored inline comment on
the diff line its subject lives on — never buried in a reply on a
thematically-adjacent thread. Reserve replies for continuing the same finding's
thread (adding evidence to it). Before posting a finding as a reply, ask: does this
belong at a different line than the parent thread? If yes → new anchored comment.

**Why:** Folding a distinct finding into a reply on a related thread hides it — it
does not appear at its own code location, does not survive as an independent thread,
and reads as commentary on the parent. Thread-relatedness ≠ line-relatedness.

**Where:** wk-pr-review Phase 5 "Follow-up finding after a review is posted" —
HARD RULE "a distinct finding anchors at its own line."
