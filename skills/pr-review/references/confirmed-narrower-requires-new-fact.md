**Rule:** "Confirmed but narrower/broader" justifies a bot-thread reply or body
anchor only when it cites a *new fact* the bot's comment lacked — a grep result,
test run, reachability/trigger check, or amplified downstream target. A standalone
opinion about priority, blast radius, or "worth fixing now" is not narrower; it is
Confirmed → silent skip.

**Why:** The dedup table allowed "Confirmed but narrower" as a justified-reply
category without defining the bar, so an agreement-plus-editorial-gloss got
relabeled "narrower" and folded into the review body. That is exactly the
"narrating bot validation" the silent-skip HARD RULE forbids. Pinning the bar to a
new fact (not an opinion) closes the loophole.

**Where:** Phase 4 dedup table — the "Confirmed but narrower" row plus the new-fact
gate and the negative/positive example pair beneath the table.
