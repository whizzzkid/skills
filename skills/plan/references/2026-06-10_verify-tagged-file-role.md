- **Rule:** When the user tags a file by path and describes its role, read
  the file's actual purpose and compare; if a sibling is a better match for
  the described role, surface the mismatch before drafting.
- **Why:** Accepting a mis-tagged file at face value plans changes to the
  wrong file — the user expects the contradiction to be flagged.
- **Where:** Step 1 Research — "File-role sanity check".
