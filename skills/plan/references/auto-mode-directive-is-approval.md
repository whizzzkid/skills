**Rule:** In auto mode, an unambiguous implementation directive already present in
the user's original prompt ("fix this", "implement X", "make this change") is plan
approval. Present the plan, then proceed in the same turn — do not block on a
second "proceed?".

**Why:** Re-asking what the original directive already authorized is over-gating.
The Step 5 HARD RULE ("wait for explicit approval") was applied mechanically
without recognizing that auto mode + a clear imperative already constitutes
approval. Block only when the plan is speculative or intent is genuinely unclear.

**Where:** Step 5 (Present and Wait for Approval), qualifier under the
approval HARD RULE.
