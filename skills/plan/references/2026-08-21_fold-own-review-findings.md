**Rule** — Self-dispatched validation findings (e.g. `wk-arch-review`) are mandatory corrections, not proposals requiring user consent. Fold them into the artifact immediately.

**Why** — The plan's own process generated them; asking "want me to apply these?" treats the agent's own review output as external feedback and wastes user attention on a non-decision.

**Where** — `SKILL.md` → Step 4 → *Self-generated review findings*; Common Mistakes → *Asking permission to apply own findings*.
