**Rule:** In Step 0 grill/clarify/decision flows, ask one question per message and
wait for the answer before asking the next. Never present a batched or numbered list
of questions, even when each carries a recommended default.

**Why:** A wall of simultaneous questions is overwhelming and hard to answer cleanly;
one-at-a-time keeps each decision focused and the answers unambiguous. Generalizes the
wk-pr-resolve one-comment-at-a-time rule to every clarifying/grilling/decision flow.

**Where:** Step 0 (Grill). Replaced the prior "ask the minimum set of questions
(max 4) via AskUserQuestion" guidance, which optimized round-trips over the user's
stated preference.
