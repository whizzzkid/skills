# Extended Mechanical Sweep Catalog

Part of the Step 2 catalog — apply each row under the **same unconditional rule**
as the inline catalog whenever its trigger matches. These are lower-frequency,
shape-specific sweeps relocated here to keep `SKILL.md` under the body-size
ceiling; relocation does not lower their priority.

| ID | Trigger | Check | Severity | Fix / escalation |
|---|---|---|---|---|
| 2.94 | Diff adds or edits a parser that converts numeric text before validating a canonical version, identifier, or serialized-number grammar | Conversion erases spelling differences such as leading zeroes or a leading plus. A broad text match followed by date/range validation can therefore accept a non-canonical alias of a valid value. | Blocker | Validate the raw component against the canonical grammar before conversion; add regression cases for distinct spellings that normalize to the same number. |
| 2.93 | Diff selects a free port by binding, closes that listener, then launches another process on the number | The close→child-bind handoff races every other binder. Connection polling only waits on the lost port; it cannot recover the child after `EADDRINUSE` or prove the responder is the expected service. | Suggestion | Bound the full launch attempt: reserve a fresh port, start the child, validate its protocol greeting, terminate on bind/startup failure, and retry with a new reservation. |
| 2.92 | Diff adds or changes a real-browser harness beside an existing harness | Compare the complete deterministic-profile preference set, not only visible debugging flags. Inline lists can look equivalent while omitting update, telemetry, or remote-configuration controls. | Suggestion | Centralize invariant offline preferences and compose harness-specific additions. Require exact shared-key/value parity before accepting copied setup. |
| 2.91 | Diff adds or changes a stable test identity used by typed code, a static fixture, or sibling runners | Grep every representation of the identity. A static fixture that cannot import the typed constant must receive the value at runtime; repeating the literal creates an independent source that a one-site edit can silently stale. | Suggestion | Keep one typed source and inject it through the fixture URL, local server, or template substitution. Reject copied literals as parity evidence. |
| 2.9.2 | Spec introduces an event-sourced materialized-view / dual-write (table + event log) | Four contract failure modes look like one: (a) is "authoritative" scoped to mutations-only or all-writes? — a creation baseline written straight to the table with no event breaks event-replay reconstruction; (b) is every write path (create, ingest, re-ingest, webhook, reaction) enumerated and assigned event-first or baseline-only? — an undifferentiated re-ingest silently mutates user-facing columns outside the event log; (c) is "atomic" backed by an explicit transaction, not just the HTTP request boundary? — two sequential writes partially commit on crash/drop/exception between them; (d) is the fold ordering deterministic under same-timestamp writes? — `created_at` alone collapses, use `(created_at, id)`. | Blocker | Scope authority explicitly; enumerate+assign every write path; require a transaction or flag partial-commit risk; tie-break the fold by `(created_at, id)`. Re-ingest column split: identity/discovered-once (write-once when NULL), always-refresh (overwrite), mutable user state (frozen on re-ingest, mutation path only). |
| 2.68 | Markdown intra-doc anchor links to emoji/punctuation-prefixed headings | GitHub slug trims leading/trailing hyphens, keeps internal `--` (` — `→`--`); presence-only ref-vs-heading compares miss `(#-x)`/`--` cases. | Blocker | Match the doc's rendered TOC links as ground truth; fix `(#-x)`→`(#x)`. |
| 2.34 | Spec/doc routing claim (which method a gate calls, which path bypasses a hook) | Grep the PR review thread for reviewer statements on the same routing. | Blocker | A reviewer who read the source is ground truth; resolve contradictions before asserting an inferred claim. |
| 2.38 | New/renamed default-or-fallback constant | Grep all files for string literals describing the OLD default behavior — display-label and logging helpers often hard-code it, missed by a call-site-only sweep. | Blocker | Update each stale literal or justify; a logging path emitting the old name looks correct to operators. |
| 2.47 | Bash fake/stub that branches on arg/URL content or writes output a real tool emits only under a flag | (a) A matched branch with no terminal `exit`/`return` before its `fi` falls through to the sibling's response — a test omitting that branch's params passes via the wrong path. (b) A stub writing output unconditionally, ignoring whether the gating flag (`--fail-with-body`, etc.) is in `$@`, makes a production regression away from that flag undetectable. | Blocker | End each branch with explicit `exit` returning its own fallback (`echo '[]'; exit 0`); gate conditional output on flag presence (`for a in "$@"; do [[ $a == --flag ]] && has=true; done`). Model both flag-present and flag-absent paths so the stub is a contract gate, not a shape-mimicker. |
| 2.41 | Comment claims a concurrency/signal race is "eliminated"/"removed" | A reorder of `signal.Stop` (or equivalent) narrows but does not drain a buffered channel — a queued signal still executes the exit path. | Suggestion | Reword to "narrows the window" unless a done-channel/atomic-flag guard truly closes it; Blocker if the comment is load-bearing for safety. |
| 2.42 | New parameterized integration test iterating a helper's nil/error paths | Grep the helper's unit spec; if it already asserts all iterated cases return the same value, the integration iterations re-test internals. | Suggestion | Keep one representative case at the integration boundary; drop the rest. |
| 2.45 | Diff adds a seed/sync/fetch step that gates a baseline read before a downstream write-back | The write-back (or any downstream mutation) must gate on the seed helper's actual **return value**, not a re-check of the seed's trigger precondition (`if X.success?` when the seed also ran on `X.success?`). A seed that only blocks itself leaves the write-back running from a stale baseline — the clobber it was added to prevent. Also treat a command exiting 0 with empty stdout (`git show` of a missing blob) as failure. | Blocker | Capture the helper's return value and gate the write-back on it; add an `out.strip.empty?` guard. |
| 2.46 | Validator over a partial-override / optional-field struct (empty = keep existing) | All-or-nothing drop discards valid overrides when any field is invalid; one bad field is a per-field hallucination, not a corrupt record. | Suggestion | Validate per-field: zero+log invalid fields (fail-open), keep valid, drop the record only when all fields invalid. |
| 2.39 | Ruby diff (comments, lambdas) | When `.rubocop.yml` enables `Style/AsciiComments`, grep new `+` comment lines for non-ASCII (`[^\x00-\x7F]` — em-dash, curly quotes, arrows). | 2.50 | Diff adds a log-level filter (custom `io.Writer` routing by string content) | Grep every failure-path log call in the package for the token the filter matches; a site using a reformatting helper (e.g. `[session]`-prefixed) that strips the token is a silent gap — the filter drops the diagnostics its own doc comment promises. | Blocker | Emit the filter's token at every failure callsite or match the helper's format. |
| 2.31 | Added jq `else .` | Grep jq type-dispatch fallbacks. | Suggestion | Use `else empty` or prove all unlisted types render OK. |
| 2.32 | Go type widening | Run `goimports -l` on changed Go files when repo has `go.mod` and CI runs goimports. | Blocker | Run before clear. |
| 2.51 | Test redirects a global logger | Grep test files for `log.SetOutput(nil)` — it sets the global writer to nil, not stderr; a later `log.Printf` in any test in the same binary writes to nil and hangs until timeout. | Blocker | Save/restore: `orig := log.Writer(); … t.Cleanup(func(){ log.SetOutput(orig) })`. Never reset a global logger writer to nil. |
| 2.36 | Named returns + deferred cleanup that reads a named return | Grep for `return <zero-literal>, ...` after the defer is established. An explicit return sets the named returns *before* deferred funcs run, so cleanup sees the zero value (e.g. `os.RemoveAll("")` → silent no-op, leaked resource). | Blocker | Assign then bare-return (`err = ...; return`) so the named var keeps its real value for cleanup; verify any comment claiming the defer cleans up on any error path. |
| 2.53 | Loop records a first-occurrence index in a map (`seen[key]=i`) to warn-on or dedup repeats | Confirm a match path `continue`s (or otherwise skips) the `seen[key]=i` assignment — an unconditional overwrite advances the "first seen" pointer to each new duplicate, so 3+ occurrences misreport the origin index. A 2-occurrence test cannot expose it. | Suggestion | After emitting the duplicate warning, `continue` so the original entry survives every later collision; require a ≥3-occurrence test case. |
| 2.52 | Helper extracted from / wired to accept `context.Context` | Grep the helper body for `context.Background()`/`context.TODO()` when the calling function takes a `ctx context.Context`/`parentCtx` param — caller-supplied cancellation (SIGINT, timeout) is silently dropped. A `Canceled` case that became unreachable confirms the context was never plumbed; asymmetric coverage vs a sibling function is a signal. | Blocker | Add `parentCtx context.Context` as the helper's first param with a `nil → context.Background()` guard; handle both context error cases when cancellable from outside, matching the sibling. |
| 2.54 | Build script passes `-ldflags "-X pkg.Symbol=value"` (or any stringly-typed cross-language symbol contract) | The symbol name is an unchecked contract between the builder and the consuming language; a string-match assertion in the builder's own test does not lock the symbol name or output path, and a rename on either side passes both suites silently. Verify a test builds the real binary with that exact flag and asserts the stamped value via the binary's own output (`--version`). | Blocker | Add an end-to-end stamped-binary exec test; a builder-side string match is insufficient coverage. |
| 2.18 | Removed named constant | Grep post-rebase diff for the literal value. | Suggestion | Restore constant or extract helper when literal appears at ≥2 non-comment sites. |
| 2.19 | New subprocess/LLM/network call site with a hardcoded `context.Background()`/`context.TODO()` | If the enclosing function has a live cancellation context available (a `context.Context` field on a received struct, or a wrapper embedding one), the literal breaks SIGINT/SIGTERM propagation to in-flight work. | Blocker | Forward the available app/request context; a nil-guard in the callee makes forwarding safe. |
| 2.30 | Source fix with committed artifact | Detect `.wasm`, generated code, `go:generate`, `go:embed`, build output. | Blocker | Rebuild and re-commit before clear. |
| 2.49 | Tempfile response capture in a curl error handler (`mktemp` + `-o "$f"` + `cat "$f"`) | `-f`/`--fail` exits before writing the body to `-o` on HTTP 4xx/5xx, so the handler reads an empty file on exactly the failure cases it targets. | Blocker | Use `--fail-with-body` (curl 7.76+) or drop `-f`; the response file must be written on error for the capture to work. |
| 2.25 | New bash `trap` | Grep whole file for overlapping signal handlers. | Blocker | Combine traps or use append helper. |
| 2.57 | Diff adds a field to a structured context/payload consumed by an LLM skill or prompt | Grep the consumer skill/prompt file(s) for a reference to the new field. | 2.56 | New/modified tests | Grep for self-referential equality (`expect(x).to eq(x.sort())`) and no-op `&& true` after `||`. | Blocker | Build independent expected values; propagate `false` in fail paths. |
| 2.55 | Log/output parse pipeline or multi-branch diagnostic guard | (a) A regex narrowed to fix overreach (e.g. `[^ ]+\.json` from `.+\.json`) silently drops inputs with spaces/Unicode — enumerate the full input space before accepting; prefer `sed -n 's/.*anchor//p'` (tail-of-line, all chars) over a character-class exclusion when the value format is unconstrained. (b) A message branch keyed on a proxy variable (e.g. stderr emptiness) instead of the actual discriminant (parse result vs file existence) fires the wrong message on orthogonal failures. | Blocker | (a) Use a space-safe extraction; (b) give each distinct failure mode its own condition and message — never branch on a proxy when the discriminant is available directly. |
| 2.37 | Gate reorder moves a cheap guard before a deeper call | Reordering short-circuits a failure path earlier → calls it used to make become unreachable. Enumerate every now-unreachable call; check each `not_to receive` test covers all, not just the deepest. | Suggestion | Add the missing negative assertions; escalate to Blocker when a now-unreachable call was previously unstubbed and would hit the network/a real dependency. |
| 2.59 | Diff adds/extends a generator or automation that writes a value (count, version, enumerated list) into a file | The tool is now the source of truth for that value — grep every other file for the same value and confirm the same automation updates each consumer. A value kept in sync in file A but hand-maintained in file B silently drifts the moment the count changes. | Blocker | Extend the generator to cover every consumer, or document the out-of-scope consumer in the same diff. |
| 2.60 | Diff edits/removes/maintains an enumeration/list/config artifact (doc, prompt, manifest) that reads like a source of truth | Grep the whole repo for the artifact's filename and the values it lists to find the real runtime consumer. If nothing reads it at runtime, it's drift-prone documentation, not load-bearing — the live consumer discovers the data itself and the artifact (plus any generator syncing it) is duplication. A maintained count with no enforcing consumer is a future drift blocker. | Suggestion | Prefer count-agnostic prose over a hand-maintained count; flag the artifact and its sync machinery as vestigial when no runtime consumer reads it. |
| 2.20 | Application code + CI pipeline | Extract net-new env reads; locate invoking pipeline steps; verify allowlist forwarding. Diff touches a compose `environment:` or plugin `env:` → full-path audit: grep every script+library in the container's runtime call graph (not just diff delta) for env reads, diff against the forwarding list, run a sibling-template consistency check. **Wholesale `env:` list replacement (e.g. a ported template) → diff the full new list against the `origin/$BASE` version of the same file**, not just the diff delta. | Blocker | Forward vars in native/container steps; exempt auto-injected prefixes only for native non-container steps. Surface any runtime read without a forwarding entry (incl. called libs); same-role siblings forward the same set. A var present in base but absent from a replaced list is a candidate dropped-forwarding regression → re-add or justify. A spec deleting a var and asserting the script's own default = intentional omission → `question`. |
| 2.61 | Diff deletes a file | For every deleted file, grep the entire repo (comments, docstrings, string literals — not just code/symbol references) for the deleted file's basename. A neighboring build/codegen/sync comment naming the file (e.g. "keep {file} in sync") compiles cleanly after the deletion, so the symbol-keyed sweep (2.8) misses it and the stale reference ships. | Blocker | Fix or remove each surviving mention in a non-historical file in the same PR. |
| 2.62 | Diff adds/edits a `rescue`/`catch`/`except` block that calls a typed API (sorbet sig, TypeScript, mypy, typed Go params) | The error path must satisfy the same typed-argument contract as the happy path — a sweep that checks only happy-path signatures (2.7) misses it because a handler reads as defensive. Grep the callee signature; verify every argument type, especially an identifier/class/module param a plain String could be wrongly passed for. A raise inside a handler (e.g. `TypeError`) converts a soft-fail into a hard crash at the moment of degradation — strictly worse than the error it handles. | Blocker | Fix the argument type to match the sig so the handler cannot raise. |
| 2.63 | Diff touches a shell script | Three recurring quoting/precedence gaps a symbol sweep misses: (a) a flag/arg list built as a whitespace-joined string (esp. `echo "$x" \| xargs -I{} echo --flag={}`) then re-expanded unquoted → word-splits any path with spaces; (b) `\|\| true` immediately followed by a pipe — `\|` binds tighter than `\|\|`, so the stage after the pipe is dead code; (c) an external command (e.g. `tput`) on a success path under `set -e` aborts when it fails or `$TERM` is unset/dumb. | Blocker | Build arg lists as a bash array expanded `${arr[@]+"${arr[@]}"}`; parenthesize the `\|\|`-guarded command so the pipe does not regroup; guard success-path external commands with `2>/dev/null \|\| true`. |
| 2.64 | A readiness/mergeable claim follows a bot re-review | A bot can post blocker-severity findings only in its top-level summary comment (`issues/comments`), with no inline `reviewThreads` entry — "no new inline threads" is not "no new findings", and green CI does not mean mergeable. | Blocker | Fetch `mergeStateStatus`/`reviewDecision` directly (source of truth) and grep the latest bot issue-comment/review body for severity markers ("Major", "blocker") before declaring ready; never infer mergeability from CI status or inline-thread count alone. |
| 2.65 | A guard/type pattern appears ≥2× in one file, applied inconsistently | Intra-file symmetry of an established pattern — each line looks locally fine, so a general pass misses it. | 2.66 | Diff parses an `Authorization`/`WWW-Authenticate` header (auth-scheme + credentials) | RFC 7235 defines `auth-scheme` as case-INSENSITIVE and the scheme/credentials separator as `1*SP` (one-or-more spaces). A regex matching a fixed-case scheme literal (`Bearer`) or a single literal space is non-conformant — it passes mechanical review but rejects valid clients. | Suggestion | Match the scheme case-insensitively (`/i`) and the separator as one-or-more spaces (`\x20+`/`\s+`); real clients usually send canonical casing + one space, but a conformant server must accept both variants. |
| 2.67 | Migration adds/changes a load-bearing schema invariant (CHECK constraint; non-unique index backing an app-enforced no-FK association; load-bearing column default; append-only table — `created_at`, no `updated_at`) | A later migration dropping the invariant passes silently unless the repo's schema-guard/lock spec asserts it — the migration itself is correct, yet the regression hole is real. | 2.69 | Test asserts "accepts every valid enum value" by looping the same constant that *defines* the enum (e.g. `enum :x, CONST.index_by(&:itself)` with `build(...).valid?` over `CONST`) | Tautological — the accepted set is `CONST` by construction, so the loop can never fail; it also misses a dropped `validate:` flag and (since `build` never persists) any DB CHECK-constraint drift. | Blocker | Require (a) `create`/persist so DB CHECK constraints run, and (b) an independent exact-match assertion (`expect(Model.xs.keys).to match_array(Model::CONST)`) guarding enum drift — never a loop over the defining constant. |
| 2.70 | Nil-guard added for a schema-nullable structured column (JSON/JSONB/`hstore`, or a Go map from `json.Unmarshal`) | A non-nil-only guard (`&.`, `.fetch`, `x != nil`) still crashes on a wrong-shaped value: the same out-of-band writer (absent key, backfill, migration) that yields nil can yield a JSON array (`TypeError`) or scalar (`NoMethodError` on `#fetch`). | 2.72 | A finding proposes replacing `T.untyped`/`any` with a precise type on a param/return | Infeasible if the framework's type stubs (RBI/`.d.ts`) don't declare a member the body dereferences on that type — runtime-added accessors (framework mix-ins/metaprogramming) are the blind spot, and a linter-banned `T.unsafe`/`any`-cast leaves no bridge. | 2.73 | A callee returns a bare scalar/bool derived from a condition, and a caller immediately re-checks that same condition against the same input (a second reference to the constant/set/enum the callee's branches already encode) to drive control flow | Two independent encodings of one rule that silently diverge when the input set changes in one place only; compiles and passes tests. | 2.75 | A broad `rescue <ParentError>` returns a fail-closed default (empty/deny/nil) for the whole hierarchy | Fail-closed conflated with fail-silent: some subtypes are the documented steady state (deny quietly), others are should-never-happen config/deploy bugs that will never self-heal and must page. | 2.76 | External/env input parsed with `String#to_i` / `parseInt` / `atoi` where `0` is load-bearing (kill-switch, "unlimited", "disabled") | These parsers never raise — a malformed string (`"fifteen"`) silently becomes `0`, no exception or log.
