- **Rule:** State derived from a produced artifact must be gated on the artifact's production fidelity — a degraded, partial, or fallback production path voids any state inference drawn from the artifact's content or existence.
- **Why:** A summary comment produced in degraded mode rendered with zero findings listed; the existence of the artifact was taken to prove findings were posted, but the degraded path omits exactly the content the inference relied on.
- **Where:** Step 3 subagent stance (Artifact-provenance-aware); hunt category (Artifact provenance).
