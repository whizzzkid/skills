- **Rule:** The `## Ticket` PR-body section emits exactly one ticket link — the
  ticket being worked on, derived from the branch/commit. Never add `Related:`,
  `Epic:`, or parent-ticket lines unless the user explicitly requests them.
- **Why:** The PR description is scoped to the work item, not the epic hierarchy.
  A parent-epic link adds noise and is not actionable for reviewers.
- **Where:** Stage 3 Description reference.
