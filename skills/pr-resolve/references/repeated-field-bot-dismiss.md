**Rule:** Before presenting a judgment-required finding, check the session `dismissed` list and prior-round notes for the same field/concern class. If a prior dismissal exists, surface its reason inline, default to `(d)`, and ask once to confirm or override.

**Why:** A bot re-firing on a previously-dismissed field from a different angle ("redundant" vs "unused") is the same underlying decision. Presenting it as fresh judgment-required forces the user to re-state the same rationale.

**Where:** Step 4, bot-handling bullets.
