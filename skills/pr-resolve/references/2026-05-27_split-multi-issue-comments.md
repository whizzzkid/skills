- **Rule**: Split a single reviewer comment with N distinct sub-items into N per-item suggestion blocks when each sub-item has a different tradeoff.
- **Why**: Bundling forces a single `(a)/(e)/(d)/(s)` answer across sub-items with different correct decisions, stripping the user's ability to differentiate.
- **Where**: wk-pr-resolve "Split multi-issue comments into per-item suggestions" (Step 4/5 region, after "Merge duplicate findings").
