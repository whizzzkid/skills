- **Rule:** Step 5 (Consult) is execution-free. Obvious-fix items get **queued** into `fixes_to_apply`, not applied mid-Step-5. Step 6 runs the unified execution pass once all judgment-required items are triaged.
- **Why:** Auto-applying obvious fixes before the judgment-required loop forces commits to land while the user is still mid-triage — the user cannot see the full picture of what is about to change before code starts moving. Inverting to triage-first preserves single-commit-per-fix while letting the user review every accepted change in the after-decisions summary before anything executes.
