- **Rule:** Once a reply that answers or fixes a finding is posted, resolve that
  thread in the same action — no separate confirmation ask for the resolution.
  Hold a thread open only when its remaining content is a genuine follow-up
  question needing more discussion.
- **Why:** Existing Hard Rule 3 scopes *which* threads may be resolved
  (only ones worked on) but under-specified *when* — so after posting
  fix-confirmation replies the agent treated resolution as a distinct step and
  asked the user whether to also resolve, an unnecessary round-trip. A reply that
  itself resolves the finding makes resolution the default action, not a question.
- **Where:** Hard Rule 3 — added the auto-resolve-after-reply sub-bullet.
