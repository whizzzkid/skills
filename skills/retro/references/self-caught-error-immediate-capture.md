**Rule:** A self-caught error — discovering a bug, finding a missing check, or correcting your own code mid-task — triggers an immediate `wk-learn` in that same response, before/alongside/after the fix commit. Do not defer it to retro.

**Why:** The top "capture in real time" HARD RULE already named "self-caught error", but a self-caught hook bug was still only logged at retro time — the generic mention failed to steer. Deferring collapses a multi-step diagnosis into one vague sentence and loses the exact error mode and moment of discovery. Re-violation → the rule was escalated with an explicit, concrete bullet.

**Where:** `SKILL.md` "HARD RULE: capture in real time" section — the dedicated "Self-caught errors count, not only user corrections" bullet.
