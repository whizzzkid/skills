# Meeting notes are leads, never citations

**Rule** — in WRITE mode, treat meeting notes only as a list of claims to validate. Re-anchor each claim to a primary
source (code, vendor docs, tickets) before it enters the doc, or carry it as an open question. Never name speakers,
quote attendees, or link private notes.

**Why** — the user stopped a spec mid-draft: it was quoting people from meeting notes. A shared design doc that
attributes statements exposes private conversations and rests on hearsay. The authoring flow had no rule against it.

**Where** — `SKILL.md` → Step 4 → WRITE mode.
