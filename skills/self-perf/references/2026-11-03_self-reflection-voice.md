# Self-review prose is action-first and self-directed

- **Rule:** Write self-review claims as what the user did, with active declarative verbs. Render prior feedback
  themes as self-directed habits; never "I was asked/told to", "I tried", or "helped with". State a miss as a learning
  whose correction is already in motion.
- **Why:** A draft paraphrased past review themes as "I was asked to…", implying a manager directed the work. The user
  corrected it twice: no one did the asking, and the whole reflection should read as what they did. The existing
  weak-verb table covered vague verbs, not attributed or passive voice.
