# Preserve user-owned sections

**Rule** — record sections the user marks final or keep-as-is, exclude them from broad polish passes, and reopen them
only on an explicit section-level request.

**Why** — treating every section as editable lets later condensation overwrite content the user already approved.

**Where** — `SKILL.md` → Stage 2 → Revision boundaries.
