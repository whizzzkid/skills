- **Rule:** Standup day markers are top-level `•` bullets; each
  achievement/priority/blocker is its own indented `  •` sub-bullet on its own
  line — never a bare label with items `·`-joined on one line.
- **Why:** The inline single-line example contradicted the canonical
  `wk-slack §Standup Snippet` it claimed to delegate to, so the agent rendered
  concatenated items.
- **Where:** Sub-command `start`, Stage 4b (example now mirrors wk-slack).
- **Supersedes:** the prior single-line `👈🏽 Yesterday: {item} {url}` example.
